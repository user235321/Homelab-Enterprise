# Roadmap

This roadmap outlines the planned evolution of the Enterprise Home Lab.

The laboratory is continuously expanding as new technologies and services are implemented. Features will be completed according to learning objectives rather than following a fixed release schedule.

---

# Infrastructure

- Additional Windows Servers
- Additional Windows Clients
- Additional Ubuntu Servers
- Second Domain Controller
- Multi-site Active Directory

---

- Windows Server Failover Features

# Long-Term Goals

The long-term objective is to build a realistic enterprise environment capable of supporting:

- Enterprise Infrastructure Administration
- Windows Security Hardening
- Active Directory Administration
- Security Monitoring
- Incident Response
- Blue Team Exercises
- Red Team Testing
- Continuous Learning
